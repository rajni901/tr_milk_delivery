Everything You Need

Built for Dairy Delivery Businesses

From corner dairies to large milk rounds — manage every subscription, route and driver from one clean Odoo interface.

🗺️

Delivery Routes

Create named routes with a driver, active delivery days and a coverage area description so drivers know their territory.

📋

Customer Subscriptions

Daily, alternate days, weekly or custom schedule per customer. Pause, resume or cancel with one click. Separate delivery address supported.

📱

Mobile Driver App

No install, no login. Driver scans a QR code once and bookmarks the URL. Sees all stops in order — taps ✓ Delivered at each door.

📄

Daily Delivery Sheets

Auto-generated from active subscriptions each morning. Confirm, print PDF, or let drivers mark status directly on their phone.

💰

Customer Wallet

Prepaid balance per customer. Auto-deducts the delivery cost when the driver marks done. Full transaction history visible.

🧾

Auto-Invoice

At month end, generate one invoice per customer from all delivered lines. Weekly or monthly billing in seconds — no manual entry.

📷

QR Code for Driver

Generate a QR code from the route settings. Driver scans once, bookmarks the page, uses it every day. No link sharing needed.

🎄

Holiday Management

Define public holidays or customer vacations. Deliveries are automatically skipped during sheet generation — zero manual work.

🔢

Stop Sequencing

Drag to reorder customer stops on each route. The driver app sorts by stop number — shortest path, zero confusion for new drivers.

⏱️

Auto-Schedule Cron

Enable a cron job to auto-generate all delivery sheets every morning at 5am. No manager action required each day.

🗓️

Calendar View

All delivery sheets on a calendar, color-coded by route. Spot coverage gaps and busy days at a glance.

👤

Customer Portal

Customers log into My Account → see delivery history, wallet balance, and pause or resume their own subscription.

Quick Setup

Up and Running in 7 Steps

1

Install the Module

Apps → Search "Milk Delivery" → Install. A new top menu appears instantly.

2

Create Delivery Routes

  • Route name, driver, delivery days
  • Coverage area description
  • Generate driver QR code
3

Add Subscriptions

  • Customer, product, qty, price
  • Assign route & stop number
  • Set custom delivery days if needed
4

Generate Daily Sheets

Manual: Operations → Generate Today's Sheets
Automatic: Enable cron at 5am

5

Driver Marks Deliveries

Opens personal URL on phone → sees stops → taps ✓ Delivered after each door.

6

Invoice at Month End

Operations → Create Invoices → set dates → one invoice per customer generated automatically.
