Configuration Steps

1

Install the Module

Go to Apps → Search "Milk Delivery" → Install

A new top menu "Milk Delivery" appears with Operations, Subscriptions, Wallets and Configuration.

2

Create Delivery Routes

Go to Milk Delivery → Configuration → Delivery Routes → New

  • Enter route name (e.g. North Zone)
  • Assign a Driver user
  • Set active delivery days (Mon–Sat)
  • Fill in Coverage Area (Sector 15–17, Model Town)
  • Click 🔑 Generate Link → share QR code or WhatsApp link with driver
3

Create Customer Subscriptions

Go to Milk Delivery → Subscriptions → New

  • Select Customer and Product (e.g. Full Cream 1L)
  • Set Qty per Delivery and Unit Price
  • Assign the Route and Stop #
  • Set Delivery Address if different from billing
  • Toggle Use Custom Days for alternate/weekly delivery
4

Generate Daily Delivery Sheets

Option A (manual): Milk Delivery → Operations → Generate Today's Sheets → Generate

Option B (automatic): Settings → Technical → Scheduled Actions → "Milk Delivery: Auto-Generate Daily Sheets" → Enable → set time to 5:00 AM

5

Driver Marks Deliveries

Driver opens their personal URL on phone → sees today's stops → taps ✓ Delivered after each stop.

http://yoursite.com/milk/driver/UNIQUE_TOKEN
6

Create Invoices at Month End

Go to Milk Delivery → Operations → Create Invoices

  • Set From Date and To Date
  • Click Create Invoices — one invoice per customer is auto-created from all delivered lines
  • Post and send to customers
7

Set Up Customer Wallets (Optional)

  • Go to Milk Delivery → Customer Wallets → New
  • Select customer → Click ➕ Add Deposit
  • Balance auto-deducts when driver marks delivery done
  • Customer sees wallet balance in their portal
